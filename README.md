# Tell a Whole Story in 32 Characters

A Wi-Fi network name that implies a whole story, in 32 characters or less.

## Entry

```
SheTookTheDogAndTheWiFi
```

23 characters. She left, took the dog — and the Wi-Fi. The whole breakup, in one network name. No password will ever get him back in.
